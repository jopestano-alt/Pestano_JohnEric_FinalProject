Library Manager System

A CLI-based Python application for managing books and borrowing transactions.

 Features

- View all books
- Add books
- Search books
- Borrow books
- Return books
- Save data using JSON
- Persistent storage

---

 Technologies Used

- Python 3
- JSON File Handling
- Object-Oriented Programming (OOP)
